# Python Quiz App | Interactive JavaScript Quiz

Interactive quiz app with instant feedback and live score tracking, built with HTML, CSS and JavaScript.

**Live demo:** https://soni200294.github.io/quiz-app-web/

![Screenshot](screenshot.png)

## Features
- 5 multiple-choice questions on Python basics
- Correct answer turns green, wrong answer turns red
- Live score and question counter
- Result screen with a Try Again option

## Tech Used
HTML, CSS, JavaScript

## How It Works
- Questions are stored as an array of objects (question, options, correct answer)
- Each question is rendered dynamically on the page
- The score is tracked in a variable and updated after every answer

## How to Run
Open the live demo link, or download the repo and open `index.html` in a browser.
